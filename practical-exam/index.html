교육원 자체 비행장에서 보는 시험 접수 방법이에요

먼저 확인하세요
꿈소드론교육원은 국가지정 전문교육기관이라서 교육원 자체 비행장 시험 접수 방법으로 진행합니다. 응시자격을 먼저 받은 뒤 접수해주세요.
1
사이트 접속하기
시험 접수, 결과 확인, 수험표 확인은 모두 TS국가자격시험 항공자격 포털에서 이루어집니다. 아래 버튼으로 접속하세요.
TS국가자격시험 항공자격 접속
2
"실기시험 접수" 선택
메인 페이지에서 바로 이용할 수 있는 메뉴 중 실기시험 접수를 누릅니다.
3
포털 로그인
정보수집 이용 동의 페이지가 나오면 본인인증을 눌러 로그인합니다.
항공자격 분야를 선택한 뒤 간편인증, 휴대폰 인증, i-PIN 인증 중 편한 방법으로 로그인합니다.
4
원서 접수 (실기시험)
로그인하면 바로 원서 접수 페이지가 나옵니다.
소속항공분야 기타 최초교육기관(경기_고양)꿈소 전문교육기관 이수예
이름, 휴대전화, 이메일, 주소가 맞는지 꼭 확인하세요. 주소는 동까지 적어야 면허증 발급에 어려움이 없습니다.
저장 후 다음으로 넘어가면 원서 접수 자격 선택 페이지가 나옵니다. 초경량비행장치를 선택하고 주의사항에 동의한 뒤 다음을 누릅니다.
원서접수 확인사항에서 시험구분, 자격구분, 자격명, 항공기 종류, 실기유형이 맞는지 확인하고 동의한 뒤 다음으로 넘어갑니다.
5
시험 일자 선택
시험 일자 선택 페이지에서 교육기관은 '(경기_고양)꿈소 (임혜섭)'를 선택합니다. 주의사항과 동의서를 체크하고 신청하기를 누릅니다.
신청하면 해당 월 시험으로 바로 접수됩니다.
접수 마감 주의
접수는 시험 전주 월요일 23:59까지입니다. 이후에 신청하면 다음 달 시험으로 접수됩니다.
예) 시험일 7월 7일(금) 6월 26일(월) 23:59까지접수 가능 6월 27일(화) 00:00부터접수 불가
서류 확인 중 접수가 반려되는 경우가 있으니 미리 신청하는 것이 좋습니다.
